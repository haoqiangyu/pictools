# Pictools — iPhone Duo / 折叠屏补充设计

目标：既有 Mobile2.0 页面，新增 Foldable 画板与独立姿态原型。此文档是设计交接，不代表 Flutter 运行代码已经适配。

## 依据与尺寸边界

Apple 的官方资料强调：按 compact / regular size class 与窗口可用区域适配；控制区靠外缘；每一边安全区可能不同；部分折叠时让交互控件避开弯折区；内屏竖持可保留水平栏。依据：[Design for iPhone Duo](https://developer.apple.com/videos/play/tech-talks/111466/) 和 [Prepare your app for iPhone Duo](https://developer.apple.com/videos/play/tech-talks/111461/)，核验日期 2026-11-10。

[官方规格](https://www.apple.com/iphone-duo/specs/)列出了屏幕的硬件像素，但不能把像素直接除以 3 当成已确认的逻辑点数、安全区或布局常量。本稿采样外屏 466×678、内屏 951×669 / 669×951、分屏窗口 466×669、降低可用高度 951×450。它们用于覆盖布局形态，不是对设备逻辑尺寸的承诺。图中的侧边系统区 72、书本避让带 32、桌面避让带 48 均为设计示意；实现时读取系统区域。

## 布局决策

| 场景 | 内容与控件 | 保留能力 |
| --- | --- | --- |
| 外屏 | 单列预览与参数，侧边返回／导出／更多 | 全部四工具；字段与参数可滚动 |
| 展开内屏 | 画布与检查器并列；主页显示工具与当前任务；批量显示列表与选中项 | 同一编辑上下文，无重新导入 |
| 内屏竖持 | 水平导航，上方画布，下方双列字段与主动作 | 原图比例、裁剪与输出设置 |
| 书本姿态 | 参数和控件分配到弯折区域两侧；弹层移至单侧 | 同一工具、同一参数与同一文件 |
| 桌面姿态 | 上半屏预览，下半屏输入、参数与导出 | 数值替代拖动，完整功能 |
| Split View | 按应用窗口约束回到紧凑布局；控制区位于窗口外侧 | 不因分屏重置任务 |
| PiP／系统占位 | 画布重新适应可用区域，参数独立滚动，次要操作进入更多 | 主动作保持可见 |
| 键盘 | 当前字段与完成动作可见；系统键盘示意，不自绘替代系统键盘 | 输入文本、校验、焦点恢复 |

## 状态模型与交接

布局状态与任务状态分开。任务拥有 `sessionId`、源图引用、裁剪矩形、旋转、目标宽高、格式、质量与保存状态；异步批次由独立队列管理。布局重建仅改变渲染，不触发新一轮处理或保存。

- 裁剪矩形存储为原图坐标或归一化坐标；窗口改变后重新计算图像到画布的变换，不保存旧画布像素作为裁剪数据。
- 比较保留 A/B 图片、视图模式、分界比例、图像中的缩放焦点。
- 输入过程中切换窗口，保留未提交文本和校验结果；支持时恢复相同字段焦点。
- 导出面板切换姿态时保留文件名、格式和质量；取消保存继续标为未保存。
- 批量处理保留任务 ID、当前索引和各项结果；旋转、折叠、分屏不重启队列，不重复调用系统保存。
- 会话内恢复与进程被系统终止后的恢复分开；本设计未承诺永久历史或跨进程恢复。

## Flutter 接入建议

现有页面已使用部分 `SafeArea` 与 `LayoutBuilder`，但这不自动完成 Duo 的侧边系统区、姿态与状态迁移适配。依据 [Flutter 自适应设计](https://docs.flutter.dev/ui/adaptive-responsive/general)，使用实际父约束或 `MediaQuery` 窗口尺寸选择布局，不以设备型号判定。

`MediaQuery.displayFeatures`、`DisplayFeatureSubScreen` 是否能提供目标平台所需信息，应在本项目实际 Flutter / iOS 版本中验证；不得默认它们已经完整映射 Duo reserved regions。平台未暴露必要信息时，采用原生容器或显式桥接；普通连续屏幕不要凭空制造物理铰链空洞。[Flutter displayFeatures](https://api.flutter.dev/flutter/widgets/MediaQueryData/displayFeatures.html)

优先实施：统一编辑会话 → compact/regular 布局 → 非对称安全区与系统区域 → 面板避让 → 处理队列延续 → 动态字号、读屏与键盘恢复。

## 验收矩阵

1. 裁剪进行中外屏 → 内屏 → 桌面姿态 → 分屏，4:3 与 1200×900 以及源图选区不变。
2. 调整尺寸输入中旋转／合起，值、比例锁、错误文案与焦点恢复正确。
3. 第 N 张转换中合起／展开，任务不重复，已完成项目不丢失。
4. 导出面板打开时半折叠，按钮不落在弯折区域；系统保存取消仍为未保存。
5. 左右分屏分别验证控制区的外缘位置；PiP 占位后不遮住导出。
6. 深色、最大系统字号、读屏、减少动态效果及外接键盘分别在 Device Hub / 真机验证。

Figma 原型中的姿态选择器位于产品界面之外，仅用于演示；它不是产品内的机型或姿态切换按钮。本次复用已有两张内容摄影，没有新增 AI 生图。
